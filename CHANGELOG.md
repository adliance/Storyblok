# Changelog

All notable changes to `Adliance.Storyblok` and `Adliance.Storyblok.FulltextSearch` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Package versions follow the targeted .NET version (e.g. `10.0.x` targets .NET 10).

## 10.0

### Changed

- Both packages now target .NET 10 (.NET 8 support has ended).

### Deprecated

- Support for `IActionContextAccessor` in views rendered by the `StoryblokMiddleware` is deprecated, because `IActionContextAccessor` is obsolete since .NET 10. It still works if your application registers it, but will be removed in a future major version. Use `ViewContext` in views and tag helpers, and `LinkGenerator` or `IUrlHelperFactory` together with `IHttpContextAccessor` in services instead.

## 8.x

### Added

- Slugs in `IgnoreSlugs` can start with `*` to ignore all slugs ending with a pattern (e.g. `*.php`). Ignored slugs are matched independently of a culture prefix.
- Support for the `like` filter in the stories client.
- Support for fetching private assets, including caching of asset metadata (asset content itself is not cached).
- Helper extension for easier access to signed asset URLs; links implement `IAsset` to support signed URLs as well.
- Request culture provider for the Storyblok preview editor, so the language selected in the Storyblok UI matches the displayed language.

### Changed

- Story IDs are now `long` to support the new, much larger IDs generated by Storyblok.

### Fixed

- Handling of redirects with a trailing `/`.
